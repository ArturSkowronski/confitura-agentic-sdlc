Temat: Confitura 2026, warsztat „fabryka oprogramowania”: możesz przyjść bez setupu

Cześć,

krótkie uzupełnienie przed jutrem. Jeśli setup na laptopie nie przeszedł albo nie miałeś czasu,
nic straconego: cały warsztat działa teraz w przeglądarce, w GitHub Codespaces.

1. Zrób fork https://github.com/ArturSkowronski/confitura-agentic-sdlc
2. Na forku: Code → Codespaces → Create codespace on main (maszyna 4-rdzeniowa).
3. W terminalu codespace'a: fabryka start (około 10 minut, zrób to przed warsztatem).

Codespaces jest darmowy dla kont GitHub Free: 120 core-godzin w miesiącu, czyli 30 godzin na
maszynie 4-rdzeniowej. Bez karty GitHub po prostu blokuje użycie po wyczerpaniu limitu,
nie wystawia rachunku. Instrukcja: warsztat/start.md w repo.

Nowość dla wszystkich: każdą lekcję możesz zacząć od zera (fabryka lekcja N), sprawdzić
(fabryka sprawdz N), a gdy utkniesz, uruchomić autopilota (fabryka autopilot N, startuje Claude Code) albo zajrzeć do gotowego wariantu w rozwiazania/lekcja-NN/.
